# Анализ эффективности нового алгоритма рекомендаций (A/B тест)

## 📌 Описание проекта
Проект посвящен оценке влияния нового алгоритма рекомендательных систем на вовлеченность пользователей мобильного приложения. Основная задача — проверить, увеличивает ли персональный подбор контента глубину просмотра страниц в приложении.

## 🛠 Технологический стек
* **Python** (Pandas, Numpy) — обработка и агрегация данных.
* **Matplotlib, Seaborn** — визуализация динамики, распределений и сегментации.
* **Statsmodels** — расчет размера выборки (Power Analysis), вычисление Effect Size и проведение Z-теста.
* **Scipy** — статистическая проверка гипотез.

## 📈 Ключевые этапы работы
1. **Предобработка данных:** Анализ исторических данных, работа с форматами дат, выделение "хороших сессий" (4+ просмотра страниц).
2. **Проектирование эксперимента:** Расчет необходимого размера выборки для выявления MDE в 3% при мощности 80% и уровне значимости 0.05.
3. **Валидация групп:** Проверка чистоты сплитования (отсутствие пересечений пользователей) и однородности выборок по регионам и типам устройств.
4. **Статистический анализ:** Сравнение конверсии в «хорошие сессии» среди **первых сессий** пользователей для исключения влияния лояльной аудитории.

## 🎯 Основные результаты
* **Выборка:** Группы А и В статистически однородны, значимых перекосов по устройствам и географии не обнаружено.
* **Метрика:** Доля «хороших сессий» в контрольной группе — **31.57%**, в тестовой — **31.47%**.
* **Статистика:** Получено значение **P-value = 0.5784**. При заданном уровне значимости $\alpha=0.05$ разница в -0.11% признана статистически незначащей.

## 💡 Итоговое бизнес-решение
Новый алгоритм рекомендаций **не подтвердил** свою эффективность на новых пользователях. Наблюдаемая разница вызвана случайными колебаниями данных.
