## Описание

Проект исследует рынок стартапов с точки зрения:
- Структуры сегментов (`mass`, `mid`, `niche`)
- Динамики финансирования (2000–2014)
- Эффективности типов инвестиций
- Возвратов средств инвесторам

Анализ помог ответить на ключевые вопросы:
- Какие сегменты растут?
- Где деньги возвращаются чаще?
- Какой тип финансирования наиболее устойчив?

## Ключевые выводы

1. **Самый стабильный возврат** — у `debt_financing`  
   → Предсказуемость делает его привлекательным для консервативных инвесторов.

2. **Рост венчурного рынка** к 2014 году  
   → Увеличение доли возвратов по `venture` говорит о зрелости экосистемы.

3. **Два типа рынка**:  
   - Массовый вход через `seed` и `angel`  
   - Концентрация капитала в `private_equity` и `post-IPO`
